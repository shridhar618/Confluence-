# Phase 15 -- real face recognition (replaces the earlier placeholder).
# opencv-python is straightforward on every platform. dlib (a dependency
# of face_recognition) is the one piece worth knowing about in advance:
# it's a compiled C++ library and can be slow/fussy to build from source,
# especially on Windows without Visual Studio Build Tools installed.
#   - macOS/Linux: usually just `pip install dlib` works.
#   - Windows: if `pip install dlib` fails, either install Visual Studio
#     Build Tools first, or use conda instead: `conda install -c
#     conda-forge dlib`, then `pip install face_recognition` on top.
# If dlib truly cannot be installed, attendance enrollment/verification
# will return a clear error rather than silently using a fake method --
# see app/services/face_attendance.py.
